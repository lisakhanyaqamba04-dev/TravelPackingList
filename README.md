# Travel Packing List Manager

ST. No.: ST10472860
Module: IMAD5112

## Description
This Android application is designed to help users manage a travel packing list. It utilizes parallel arrays to store data and demonstrates navigation between two screens.

## Features
*   **Screen One:**
    *   Input fields for Item Name, Category, Quantity, and Comments.
    *   "Add to Packing List" button with error handling (checks for empty fields and numeric quantity).
    *   Navigation buttons to view the list or exit the app.
*   **Screen Two:**
    *   View the full packing list (Item Name, Category, Qty, Comments).
    *   Filter view: Display only items where the quantity is 2 or more.
    *   Return button to navigate back to the main input screen.
*   **Technical Implementation:** Logic implemented using Kotlin parallel arrays (`MutableList`), loops, and `Toast` for error handling. Logs are used to track app behavior.
